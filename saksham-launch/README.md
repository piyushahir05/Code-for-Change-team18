# Saksham Launch

Create a **premium, modern, highly visual Home Page + Login Page** for a social-impact digital platform called:

# SAKSHAM

### Empowering ITI Students. Enabling Careers.

**Saksham is a digital employability ecosystem by Y4D Foundation**, designed to help ITI students and graduates build skills, connect with mentors, discover opportunities, and progress toward sustainable employment.

The website is being created for a **Mastercard Code for Change hackathon**, so the design must feel polished, innovative, socially impactful, and presentation-ready.

---

# 1. CORE PLATFORM IDEA

Saksham connects the complete ITI employability ecosystem:

**ITI Students & Graduates ↔ Faculty & Mentors ↔ Institutions ↔ Industry**

The platform brings together:

* Learning resources

* Skill development

* Soft skills

* Workplace readiness

* Mentorship

* Peer learning

* Apprenticeships

* Jobs

* Recruitment drives

* Government employment schemes

* Industry opportunities

* Career progression

* Placement tracking

The core journey should visually communicate:

### **LEARN → CONNECT → PREPARE → DISCOVER → APPLY → GROW**

The website should make the visitor immediately understand:

> **"Saksham helps ITI students turn their skills into real career opportunities."**

* Clean sans-serif body text

* Rounded cards

* Large human-centered photography

**a modern digital employability ecosystem**

**a premium editorial brand.**

Do NOT make it look like:

* A generic job portal

* A generic LMS

* A generic government website

* A corporate SaaS dashboard

* A typical college website

Instead, make it feel like:

# **Saksham — a movement that helps young people become capable, confident and career-ready.**

The final homepage should leave the visitor with one clear message:

### **"I can become Saksham here."**

Prioritize exceptional visual design, storytelling, authentic Indian vocational-training imagery, accessibility, responsiveness and a polished hackathon-demo quality experience.

Do not use lorem ipsum.

Use realistic placeholder content.

Make all navigation and CTA buttons functional through frontend routing.
